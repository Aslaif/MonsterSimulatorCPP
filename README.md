# Monster Simulator (C++)

Small C++ console game where the player selects a monster and lets it fight against other monsters in an arena-style combat simulation.

---

## Overview

This project is a simple console-based combat simulator written in C++.  
The player chooses a monster and fights against randomly generated enemy monsters.

After each battle the player can improve the monster's stats, making it stronger for future fights.

The game focuses on experimenting with basic game systems such as combat resolution, stat progression and equipment mechanics.

---

## Gameplay

The player can choose between three monsters:

- Orc
- Goblin
- Troll

Each monster has different base stats.

During the game:

- The player selects a monster
- The monster fights enemy monsters
- The combat progress is described in the console
- The game reports which monster wins and after how many rounds

---

## Progression System

After every fight the player can increase the monster's stats.

This allows the player to gradually improve their monster and survive longer battles.

---

## Equipment System

Enemy monsters may sometimes carry weapons.

If the player wins the battle, the weapon can be equipped by the player's monster, improving its combat abilities.
